# MoneyGame

Practical checklists, templates and blueprints for people who run their own
infrastructure — Docker, PostgreSQL, Kubernetes, Linux hardening, backup
and disaster recovery. Written from systems actually operated, not from
documentation.

## Free tools

- **[compose-check](https://github.com/MoneyGame-Jarvis/compose-check)** —
  scan a `docker-compose.yml` for the dozen settings that turn a hobby
  stack into an incident. Python, no dependencies, no telemetry.
